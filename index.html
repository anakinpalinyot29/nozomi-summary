ตัวช่วยอัตโนมัติ (Browser Extension)

ดึง alert ของกะจาก Vantage มา normalize ให้อัตโนมัติ — ไม่ต้อง export เอง

  • ⚡ เลือกกะ + วันที่ แล้วกดปุ่มเดียว ได้ไฟล์ Excel
  • 🔐 ใช้ session ที่คุณล็อกอิน Vantage อยู่แล้ว — ไม่ต้อง 2FA ซ้ำ
  • 📅 เลือกได้ทั้ง Day, Night หรือทั้งวัน (รวมในไฟล์เดียว)
  • 🖥️ ใช้ได้ทั้ง Chrome และ Edge
⬇ ดาวน์โหลด Extension (.zip)
วิธีติดตั้ง (ทำครั้งเดียว)
  1. แตกไฟล์ .zip ที่ดาวน์โหลดมา
  2. เปิด chrome://extensions (หรือ edge://extensions)
  3. เปิด Developer mode (มุมขวาบน)
  4. กด Load unpacked → เลือกโฟลเดอร์ที่แตกไว้
  5. เปิดแท็บ Vantage แล้วล็อกอิน → คลิกไอคอน extension → เลือกกะ+วันที่ → Export
หรืออัปโหลดไฟล์เอง (manual)
